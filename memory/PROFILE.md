# Perfil pedagógico persistente

- Objetivo deste projeto: preparação para os cargos UFMS 523 e 324 usando questões comentadas.
- Plataformas previstas: TEC Concursos e Qconcursos; execução e envio de resultados pelo estudante.
- Preferência metodológica: IA adaptativa, com evidência de retenção e sem cronograma rígido imposto pelo agente.
- Perfil pessoal, dados sensíveis e desempenhos individuais: **não registrados nesta configuração inicial**.

Alterações devem ser explícitas e limitadas ao necessário para melhorar recomendações futuras.
